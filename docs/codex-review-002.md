# Codex Review 002：ASR=0% 是死路还是护城河？

**1. "攻不破"是有价值的发现，但当前证据撑不起它。** 全链路同源（攻击者/目标/裁判全是 deepseek-chat）、目标请求全是"爆炸物/洗钱"顶级红线、模板是英文 HarmBench 的直译——三重缺陷让 0% 更像"方法太弱"而非"模型太强"。要把它变成研究发现，必须换独立裁判＋人工抽检 200 条，否则只是记录了自己的失败。

**2. 别指望 GCG/PAIR 救你。** GCG 要白盒梯度，API 黑盒做不了；PAIR 能做但烧 token、对中文对齐模型收益低。真正该做的是"换靶子"——Qwen/GLM 开源弱对齐版本地免费跑。但你说只有 DeepSeek，那唯一可行的是**降级目标请求**：从顶级红线降到灰区（擦边医疗、诱导性隐私、误导投资、隐喻政治），灰区 ASR 大概率非零。

**3. 只有 DeepSeek 的突破 = 重构叙事。** 把 CAED 从"攻击成功样本集"改成"中文模型安全强度基准"：记录失效技术、防御理由、ASR 时间趋势。护城河从"漏洞快照"（已崩，无漏洞可存）转向"谁先被攻破的持续监测＋失效技术库"。

**结论：** ASR=0 的攻击数据集不性感，但"中文模型安全性显著强于英文"是可量化、反直觉、能发论文的发现——前提是你先补灰区样本和独立裁判，让 0% 变成可信的 0%，而非方法论的 0%。
